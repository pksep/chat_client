# Информация о личном ИИ-диалоге

При нажатии на имя СЭПи открывается существующая правая модальная панель. На мобильном экране используется штатная мобильная панель. Аватар фиксирован, название и настройка звука сохраняются на сервере отдельно от поколений сообщений.

Медиа и файлы отображает ProfileAttachmentsPanel. Он получает дополнительный источник страниц из проверенной серверной истории ИИ. Это сохраняет общий просмотрщик и загрузку файлов, включая вложения старых сообщений. Исходные файлы не преобразуются и не перезаписываются. Миниатюры доступны только после проверки владельца файла.

Пересылка сохраняет указатель на исходный личный диалог. Указатель не предоставляет доступ: сервер сверяет сотрудника и организацию с авторизацией. Получатель пересланного сообщения видит только уже переданное сообщение. Открыть историю, её файлы и перейти в исходный диалог может только владелец. Чтение сведений не создаёт отсутствующий или удалённый диалог.

Проверки: переименование и звук после перезагрузки; неизменяемый аватар; общая галерея с пагинацией; чтение собственного вложения и отказ другому сотруднику; переход из пересылки своим и чужим пользователем; существующая пересылка обычных сообщений.
