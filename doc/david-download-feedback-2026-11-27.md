## Изменения

- Для обработанных изображений и видео исходный `media.size` не передаётся как ожидаемый размер скачиваемого объекта. Проверка HTTP Content-Length остаётся в Rust; для обычных файлов также сохранено сравнение с размером из сообщения.
- Слайдер получает стабильный адрес оригинала, независимо от наличия blob-предпросмотра. Авторизованные приватные blob-файлы сохраняются через нативный base64-путь, без обхода проверки доступа.
- Слайдер и меню используют общий загрузчик и одинаковый ключ файла. Параметры предпросмотра, имени скачивания и версии кеша не мешают найти уже скачанный файл и показать выбранную фотографию в папке.
- Операция скачивания в Tauri показывает проценты и подтверждает сохранение только после завершения native-запроса. Ошибка и отмена не превращаются в успех. Для браузерного скачивания сообщение говорит о начале операции: страница не получает подтверждение завершения системного скачивания.
- Копирование текста, выделения, файла и изображения показывает подтверждение. Долгая операция сохраняет плашку «Копируем…» до завершения; отклонённая запись в буфер показывает ошибку. Повторные нажатия в слайдере блокируются без потери фокуса кнопки.
- Подпись изображения использует переносимый flex-макет: время и статус остаются внутри пузыря справа внизу, текст их не перекрывает.

## Макет уведомлений

Проверен открытый [макет Figma](https://www.figma.com/design/js0Tglb1IC1NPFBvSIBzW6/SEP-ERP-Library?node-id=50248-105332). В установленной `@pksep/yui` 0.1.353 и актуальной на момент проверки 0.1.374 остаётся старое оформление Notification. Обновление зависимости само по себе макет не исправляет.

Добавлен локальный адаптер уведомления с иконками YUI: ширина 320 px с ограничением по экрану, высота от 48 px, рамка 2 px по всему периметру, радиус 5 px, перенос текста и светлая/тёмная темы. Одна плашка обновляет состояние процесса без перемонтирования; высота стека измеряется, поэтому многострочные уведомления не перекрываются. Сохранена работа native popover внутри модальных окон и доступная кнопка закрытия. Существующий Bun patch YUI дополнен хуками операций слайдера; прежнее исправление tooltip редактора изображений сохранено.
