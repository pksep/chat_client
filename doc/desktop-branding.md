# Имя «СЭП Чат» и совместимость обновлений

Видимое имя изменено в Tauri, PWA, Capacitor и нативном Android. Пакеты
`ru.pksep.chat` / `sep.pksep.app`, протокол sepchat, подписи и updater-feed
сохранены. Изменение названия не требует удаления пользовательских данных.

- Windows: сохранён прежний MSI UpgradeCode. NSIS переносит установку в
  прежний каталог и убирает старые записи только при совпадении пути.
  MSI использует ru-RU: кодировка по умолчанию en-US не поддерживает кириллицу.
- macOS: productName/CFBundleDisplayName — «СЭП Чат», системный CFBundleName
  остаётся `SEP Chat` для совместимости WebKit-хранилища. QA обновляет приложение
  со старого видимого имени на новое и проверяет сессию, черновик, перезапуск
  и открытие из Dock. Проверка прошла на Apple Silicon и Intel в 1.53.1.
- Linux: package productName остаётся `SEP Chat`, чтобы Debian/RPM имели
  допустимое имя `sep-chat`. Шаблон desktop-entry показывает «СЭП Чат».
- Имена публичных файлов GitHub Releases сохраняют ASCII. Публикация использует
  ту же таблицу имён, что и URL в updater-манифесте.

Прежние Downloads/SEP Chat и Windows-ключ автозапуска сохранены как технические
идентификаторы. Apple Developer ID для доверенной первой установки Mac требует
отдельной настройки; переименование не добавляет нотарификацию.
