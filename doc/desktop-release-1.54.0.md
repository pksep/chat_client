# Выпуск Tauri 1.54.0

20 ноября 2026 пользователь подтвердил локальную проверку инспектора, поручил
остановить локальную сборку и опубликовать Tauri.

Локальный preview `ru.pksep.chat.inspectorpreview` остановлен. Его профиль
сохранён; установленный пользовательский клиент продолжает работать.

В выпуск входят изменения `main`, включая:

- пункт «Открыть инспектор» и сворачивание в меню иконки в трее;
- русские подписи вложений с типом, количеством и именем файла;
- действия Windows-уведомлений: «Ответить», «Нравится», «Прочитано»;
- исправление индикатора открытия приложения и переходы к загрузке;
- фоновая подготовка подписанного обновления с одной кнопкой «Обновить».

Проверены browser-регрессии, типы, production build и Rust release-check.
Уведомление с полем ответа создано через API Windows в тесте без показа.

Workflow Release получил ручной запуск. Он вычисляет версию по Conventional
Commits; после появления release tag Desktop Builds собирает и подписывает
четыре платформы. Канал `desktop-stable/latest.json` меняется только после
успешной загрузки всех установщиков и проверок Linux multimedia.

На начало публикации стабильный канал содержит 1.53.6. Параллельные локальные
изменения разрешений не включены в release commit и не изменяются этой работой.
