# Выпуск Tauri 1.54.1

20 ноября 2026 пользователь поручил включить все оставшиеся изменения в `main`,
увеличить веб-версию и опубликовать Tauri. Веб-сайт пользователь развёртывает сам.

Выпуск включает изменения 1.54.0 и сохранение решений по разрешениям устройств:
микрофон, камера, геолокация, уведомления и чтение буфера обмена. Разрешения
восстанавливаются при запуске Tauri; фактическое разрешение ОС проверяется отдельно.
В профиле можно сбросить сохранённые ответы. Веб-версия увеличена до **115**.

Проверки изменений разрешений:

- 14 unit-тестов настроек и уведомлений;
- Playwright Chromium/WebKit: 41 пройден, 1 пропущен;
- ESLint изменённых компонентов и сервисов, `git diff --check`.

Ранее для остальных включённых изменений проверены production build, Rust
release-check, тесты нативного уведомления Windows и browser-регрессии.

Публикация выполняется через Release → Desktop Builds. Стабильный канал
`desktop-stable/latest.json` обновляется только после успешной сборки четырёх
платформ, проверки Linux multimedia, загрузки пакетов и проверки подписей.
Веб-деплой не запускается. Локальная сборка для демонстрации инспектора остановлена.
