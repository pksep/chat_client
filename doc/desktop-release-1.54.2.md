# Выпуск Tauri 1.54.2

Исправлена позиция полной панели реакций после нажатия «+» в меню сообщения.
Панель заменяет меню на его текущем месте. Если панель больше свободного места,
общий ContextMenu сдвигает её внутрь видимого окна по фактическим размерам.
Расчёт размещения над кнопкой с фиксированной высотой удалён: он уводил панель
к верхнему краю, что видно на записи пользователя от 23 ноября 2026.
Плавное появление сохранено; начало анимации привязано к верхнему левому углу.

Веб-версия увеличена с 115 до **116**. Веб-деплой выполняет пользователь.

Проверки:

- 4 Playwright-сценария в Chromium/WebKit: повторные открытия в четырёх точках,
  верхний/нижний/правый край окна, обычная страница и хедер Tauri;
- 2 Android-сценария: положение над клавиатурой и сохранение фокуса ввода;
- `vue-tsc --noEmit`, ESLint изменённых исходников и `git diff --check`.

Установленный Tauri использует встроенный интерфейс, поэтому для доставки
исправления требуется новая сборка. Публикация выполняется по существующему
порядку Release → Desktop Builds с проверкой всех платформ перед переключением
стабильного канала.
