## Содержание

Исправлены обычный клик, скрытие редактора и пустой отступ в закреплениях.
Переход к оригиналу выполняется явным действием общего меню. Android сохраняет
то же поведение. Неверная ссылка, HTML вместо config и пустая сохранённая
конфигурация не открывают неработающий сервер.

В Windows закреплён путь профиля, добавлена DPAPI-копия постоянного входа,
refresh cookie, организации и темы. Явный выход сохраняется и в копии; запись
ожидается перед установкой обновления. Точная причина прежнего сброса у Давида
не подтверждена: версия старого клиента неизвестна.
