# UI-библиотека

По умолчанию чат использует опубликованную `@pksep/yui@0.1.332` из npm.
Версия закреплена в `package.json` и `bun.lock`; для обычной установки достаточно
`bun install` в `chat_client`.

Локальный чат запускается командой `bun run start:dev` и открывается на
`http://localhost:5173`. Он использует пакет из npm; изменения исходников в
`sep_yui` попадут в него после публикации библиотеки и обновления зависимости.

Ошибки подчёркивает встроенная проверка: локальные словари Hunspell русского и
английского языков (`dictionary-ru`, `dictionary-en`) и движок `nspell` работают
в Web Worker. Настройки и словари браузера не требуются. Текст не отправляется
на сервер для проверки. Смешанный русский и английский текст проверяется
одновременно; грамматика не проверяется.

Проверка включена в `ContentEditor`, `Input`, `Textarea`, `Search`, тексте ссылки
и поле статуса. URL, адреса почты, упоминания, код и цифровые идентификаторы
пропускаются. В `Input`, `Textarea` и `Search` проверку можно отключить через
`:spellcheck="false"`. Пароли и адреса сервера исключены.

Для нативных текстовых полей доступна директива `vSpellcheck` из `@pksep/yui`:
`<input v-spellcheck spellcheck="false" />`. Подчёркивания не изменяют значение
поля и не попадают в отправленное сообщение.
