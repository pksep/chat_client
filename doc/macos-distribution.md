# Установка SEP Chat на Mac без ручного обхода Gatekeeper

Для публичного DMG нужны сертификат **Developer ID Application** и нотарификация
Apple. Подпись пакетов Tauri (Minisign) проверяет подлинность автообновления,
но не заменяет доверие macOS к разработчику приложения.

Потребуется [Apple Developer Program](https://developer.apple.com/programs/enroll/)
(99 USD в год или эквивалент в местной валюте). Бесплатная учётная запись не
даёт возможности нотарифицировать публичный установщик. Сертификат Developer ID
создаёт Account Holder команды. Приложение не нужно публиковать в App Store.

## Однократная настройка

1. Выпустить Developer ID Application в Apple Developer, установить его вместе
   с приватным ключом в «Связке ключей» Mac и экспортировать пару в `.p12`
   с паролем. Закодировать `.p12` в base64 для секрета GitHub.
2. В App Store Connect → Users and Access → Integrations создать командный API key
   с ролью Developer, скачать `AuthKey_*.p8`, сохранить Key ID и Issuer ID.
3. В Settings → Secrets and variables → Actions репозитория задать:

| GitHub Secret                | Значение                                                 |
| ---------------------------- | -------------------------------------------------------- |
| `APPLE_CERTIFICATE`          | Base64 экспортированного `.p12`, включая приватный ключ  |
| `APPLE_CERTIFICATE_PASSWORD` | Пароль `.p12`                                            |
| `APPLE_SIGNING_IDENTITY`     | Полное имя `Developer ID Application: Компания (TEAMID)` |
| `APPLE_API_ISSUER`           | Issuer ID командного API key из App Store Connect        |
| `APPLE_API_KEY`              | Key ID                                                   |
| `APPLE_API_PRIVATE_KEY`      | Полный текст `.p8`, включая строки BEGIN/END PRIVATE KEY |

Не добавлять эти значения в код, отчёты или сообщения чата. Ключ `.p8` создаётся
только во временном каталоге macOS runner с правами 0600 и удаляется в `always()`.
Tauri импортирует `.p12` в собственную временную связку ключей.

4. Установить repository variable `MACOS_NOTARIZATION_REQUIRED=true`, чтобы
   будущие релизы останавливались при отсутствии любого из этих секретов.
5. Создать **новый** релиз. Уже опубликованные установщики с тем же именем и
   версией не заменяются: изменение подписи и прикрепление билета меняют хеши.

Когда все шесть секретов заданы, Desktop Builds автоматически включает подпись
Apple на Apple Silicon и Intel. Частично заданная конфигурация останавливает
подготовку выпуска, вместо молчаливого возврата к неподписанному приложению.

Пока учётной записи и секретов нет и обязательный режим не включён, остаётся
явно отмеченный в Actions режим ручной установки. Он сохраняет существующие
сборки Windows/Linux и подпись Tauri, но **не обеспечивает** запуск Mac без
ручного разрешения Gatekeeper. Такой выпуск нельзя считать решением проблемы
обычной установки на Mac.

## Что проверяет пайплайн

- Tauri подписывает `.app` сертификатом Developer ID, включает hardened runtime
  с разрешениями камеры/микрофона и отправляет приложение на нотарификацию.
- Проверяется реальная подпись, ожидаемая команда Apple и bundle ID
  `ru.pksep.chat`, прикреплённый билет и принятие приложения Gatekeeper.
- Отдельно распаковывается `.app.tar.gz` для updater: та же проверка проводится
  для приложения внутри архива, а не только для исходного `.app`.
- Готовый подписанный DMG также отправляется в Apple, получает билет и проходит
  `stapler validate` и `spctl --assess`. Затем проверяется `.app` из смонтированного
  в режиме чтения DMG.
- Только после успешной проверки собираются и публикуются пакеты. Для обеих
  архитектур сохраняются отчёты `apple-distribution-*`. Повторное использование
  артефактов требует этих проверок в исходном run и отчётов для нужной версии.
- Проверки установки Tauri-обновления, перезапуска и повторного открытия окна
  из Dock сохраняются отдельно; тестовые QA-приложения не используют Apple secrets.

После подписанного релиза обычный пользователь скачивает DMG, переносит SEP Chat
в «Программы» и открывает его. Стандартное подтверждение первого запуска и запросы
доступа к камере, микрофону и экрану остаются под управлением macOS.

Процедура основана на [документации Tauri по macOS signing](https://v2.tauri.app/distribute/sign/macos/).
Проверки с настоящим Developer ID и нотарификацией требуют рабочей учётной записи
Apple; локальные unit-тесты проверяют условия выпуска, а не подтверждают доверие Apple.
