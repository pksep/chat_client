# Открытие приложения и разрешения устройств — 23 ноября

Изменения пока локальные, выпуск и выкладка не выполнялись.

## Веб и ERP

- При обычном входе веб вызывает зарегистрированный протокол приложения. Отдельная модалка выбора для звонка удалена: разрешение на запуск показывает браузер.
- Повторные загрузки этой вкладки сохраняют веб-режим. `appClient=web` явно оставляет веб; `appClient=app` запрашивает открытие приложения снова и затем удаляется из адреса. Автоматическая попытка запоминается только для вкладки: скопированная обычная ссылка не навязывает веб-режим другому человеку. Вход по QR, iPhone/PWA и обычный редирект с ERP-токеном не запускают лишний запрос.
- Иконка ERP по-прежнему обновляет сессию и открывает штатную HTTPS-ссылку чата в новой вкладке; добавлен `appClient=app`. Эта страница передаёт управление приложению, при отсутствии обработчика остаётся веб-чат с прежним входом. ERP-токен и QR не передаются в `sepchat:`/`intent:`.
- Обычная ссылка передаёт маршрут переписки и организацию. Нативный обработчик принимает только маршруты чата и HTTP(S)-организации; простой `sepchat://open` сохраняет текущую переписку.
- Ссылка звонка сохраняет точную комнату и токен приглашения. Существующая очередь ждёт SDK/авторизации; действующее приглашение сразу открывает модалку и начинает подключение. Истёкшая ссылка сохраняет прежнюю обработку ошибки.
- Пока идёт попытка передачи звонка приложению, веб-звонок удерживается. Возврат фокуса без ухода со страницы позволяет продолжить звонок в вебе; скрытие страницы отменяет ожидание. Новая ссылка отменяет ожидание предыдущей.

Браузер не предоставляет надёжного API обнаружения установленного приложения или результата системного диалога. Используются прежние сигналы видимости/фокуса; автоматический вызов протокола может блокироваться политикой браузера. Для повторного явного запуска остаётся кнопка «Открыть приложение». Реальный системный диалог и запуск установленного клиента этим браузерным прогоном не проверялись; протоколы и события моделировались локально.

## Tauri: разрешения

- Раздел профиля «Разрешения устройств» показывает отдельные строки микрофона, камеры, геолокации, уведомлений, буфера обмена и демонстрации экрана.
- Статусы относятся к сохранённому выбору приложения; системная блокировка уведомлений показывается отдельно. Доступ ОС не выдаётся за разрешение приложения.
- Статусы обновляются после выдачи доступа и сброса. Выбор источника демонстрации экрана остаётся отдельным при каждом запуске.
- Запрос микрофона/камеры перечисляет только запрошенные устройства. Отказ, Escape и отдельное согласие на камеру сохранены.

Прежняя автоматическая мобильная модалка из `ChatContainer` также удалена, чтобы не дублировать системный запрос. Её устаревшие флаги и обработчик установки удалены из `useMobileApp`; сам вызов composable и его обработчики обновлений сохранены. Установка PWA на iPhone использует прежнюю отдельную подсказку iOS.
