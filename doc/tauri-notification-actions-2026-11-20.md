# Индикатор запуска, инспектор и уведомления Tauri

Веб-счётчик — 114. Индикатор «Открываем приложение…» теперь прекращается
при потере фокуса даже без `visibilitychange`. Проверка возврата после системного
окна остаётся отдельным состоянием: уход в другое окно не оставляет кнопку
заблокированной и не открывает сайт в фоне.

В меню иконки Tauri в трее добавлены «Свернуть» и «Открыть инспектор».
Для инспектора включены Cargo-feature `devtools` и настройка окна, поэтому пункт
доступен также в release-сборке. Штатное меню браузера по правому клику не включается.

Подписи вложений локализованы на всех платформах: фото, видео, аудиофайл,
документ или файл с именем. Для нескольких вложений показываются количество
и типы с русскими окончаниями; отправленная как файл картинка остаётся файлом.
Текст сообщения и сведения о вложении показываются вместе.

В Windows добавлены кнопки «Ответить», «Нравится», «Прочитано» и поле быстрого
ответа. Эти три действия не разворачивают окно чата при успехе. Они используют
существующие серверные `/messages/topic/:id/reply`, `/reaction`, `/read`, как Android.
Нравится устанавливает ❤️, а не переключает реакцию. Ответ содержит исходный
messageId и стабильный UUID clientId; повторный callback не создаёт вторую отправку.
Действия привязаны к аккаунту, проверяются до и после запроса и очищают уведомление
только после подтверждения сервера. Неотправленный текст сохраняется в редакторе;
ошибка отметки прочтения после успешной отправки не предлагает отправлять ответ заново.

Нативные кнопки этой реализации относятся к Windows. Для macOS/Linux изменён
текст уведомлений; действие desktop-плагина там не реализует эти три кнопки.
Приём звонка и отклонение сохранены отдельно от действий сообщений.

Проверки: 50 UI-сценариев запуска в Chromium/WebKit, 5 проверок уведомлений,
8 unit-тестов предпросмотра и действий, 3 Rust-теста. Rust-тест создаёт настоящий
ToastNotification через API Windows, не показывая его пользователю.
`cargo check --release --locked`, проверка типов, ESLint изменённых файлов и
production build прошли. Нативные изменения требуют новой сборки desktop;
само увеличение веб-счётчика установленный бинарник не заменяет.
