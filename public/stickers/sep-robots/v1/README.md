Набор из 15 стикеров SEP. Идентификаторы и порядок заданы в `src/utils/stickers.ts` и соответствуют сетке стикеров в Figma, узел `46947:73859` SEP-ERP Library.

Анимации обновлены 08.10.2026 из предоставленной папки `1`: все 15 исходных WebP имеют размер 512×512 и прозрачный фон. Кадры скопированы без перекодирования; изменено только число повторов в заголовке ANIM на 0 для постоянного проигрывания. `robot-default-face-animation-512x512.webp` используется для `yes`. Статичные превью для пикера сохранены из папки `2`. В сообщениях анимация повторяется непрерывно, нажатие ничего не перезапускает.

В пикере изображения занимают 60×60, как в Figma, в пяти колонках с равномерными промежутками. Для `yes` используется `ChatGPT Image 26 … 13_52_07 1.png`, для `happy` — `ChatGPT Image 27 … 11_20_53 (3) 1.png`: их прозрачные поля отличаются от первых кадров анимаций.

В пикере используются исходные картинки из `previews/`. Для сообщений `message-previews/` содержит первый кадр каждого WebP, уменьшенный до 256×256 без обрезки прозрачных полей. Масштаб рисунка при загрузке анимации поэтому не меняется. Для генерации используйте Pillow: откройте WebP, выполните `seek(0)`, `convert('RGBA')`, `resize((256, 256), Image.Resampling.LANCZOS)` и сохраните PNG с `optimize=True`.

Отправляется идентификатор набора и стикера в метаданных сообщения, без загрузки файла, медиаконвертации и слайдера. Для старых клиентов, уведомлений и списка чатов сохраняется текст `Стикер: <название>`. Неизвестные идентификаторы не превращаются в ссылки на изображения.

По умолчанию файлы доступны в `/stickers/sep-robots/v1/`. При размещении ресурсов на другом сервере задайте `VITE_STICKER_ASSET_BASE_URL` с базовым URL каталога `stickers`.
