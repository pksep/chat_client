**Техническая документация: Кроссплатформенный чат SEPChat**

**Обзор проекта**

Данный документ описывает техническую архитектуру и реализацию кроссплатформенного чата на базе Vue 3 с TypeScript, использующего OpenIM в качестве backend'а. Чат может встраиваться как веб\-компонент, работать в полноэкранном и минимальном режимах, а также собираться в desktop и mobile приложения с помощью **Tauri v2**.

**Ключевое решение: Tauri v2 для всех платформ**

**Tauri v2** поддерживает как desktop, так и mobile платформы из единой кодовой базы:

* **Desktop**: Windows, macOS, Linux  
* **Mobile**: iOS, Android  
* **Единая архитектура**: Rust backend \+ веб\-технологии  
* **Нативные возможности**: Swift плагины для iOS, Kotlin для Android  
* **Минимальный размер**: от 600KB благодаря системному WebView

**Архитектура проекта**

**Технический стек**

* **Frontend Framework**: Vue 3 (Composition API)  
* **Language**: TypeScript  
* **Component Library**: sep-yui (внутренняя библиотека на Vue)  
* **Backend**: OpenIM Server (готовое решение)  
* **Build Tools**: Vite  
* **Cross-Platform Framework**: **Tauri v2** (desktop \+ mobile)  
* **Web Components**: Vue defineCustomElement API

**Интеграция с OpenIM**

**Tauri-специфичный OpenIM Service:**

// src/services/openim.tauri.service.ts  
import { invoke } from '@tauri-apps/api/core'  
import { listen } from '@tauri-apps/api/event'  
import { getSDK, CbEvents } from '@openim/wasm-client-sdk'

export interface OpenIMTauriConfig extends OpenIMConfig {  
  enableNotifications?: boolean  
  notificationIcon?: string  
}

export class OpenIMTauriService extends OpenIMService {  
  constructor(private tauriConfig: OpenIMTauriConfig) {  
    super(tauriConfig)  
  }

  async initialize(): Promise\<void\> {  
    await super.initialize()  
     
    // Настройка Tauri-специфичных возможностей  
    if (this.tauriConfig.enableNotifications) {  
      await this.setupNotifications()  
    }  
     
    // Слушаем события приложения  
    await listen('app-ready', () \=\> {  
      console.log('Tauri app is ready')  
    })  
  }

  private async setupNotifications(): Promise\<void\> {  
    const { isPermissionGranted, requestPermission, sendNotification } \=  
      await import('@tauri-apps/plugin-notification')

    let permissionGranted \= await isPermissionGranted()  
     
    if (\!permissionGranted) {  
      const permission \= await requestPermission()  
      permissionGranted \= permission \=== 'granted'  
    }  
     
    if (permissionGranted) {  
      this.sendNotification \= async (title: string, body: string) \=\> {  
        await sendNotification({  
          title,  
          body,  
          icon: this.tauriConfig.notificationIcon  
        })  
      }  
    }  
  }

  private sendNotification?: (title: string, body: string) \=\> Promise\<void\>

  protected handleNewMessages \= (data: MessageItem\[\]): void \=\> {  
    super.handleNewMessages(data)  
     
    // Отправляем уведомления для новых сообщений  
    if (this.sendNotification) {  
      data.forEach(message \=\> {  
        this.sendNotification?.(  
          \`Новое сообщение от ${message.senderNickname}\`,  
          message.content  
        )  
      })  
    }  
  }  
}

**Vue composable для Tauri:**

// src/composables/useTauri.ts  
import { ref, onMounted } from 'vue'  
import { invoke } from '@tauri-apps/api/core'  
import { getCurrent } from '@tauri-apps/api/window'

export function useTauri() {  
  const isTauri \= ref(false)  
  const platform \= ref\<'desktop' | 'android' | 'ios' | 'web'\>('web')  
  const deviceInfo \= ref\<any\>(null)

  const checkPlatform \= async () \=\> {  
    if (window.\_\_TAURI\_\_) {  
      isTauri.value \= true  
       
      try {  
        deviceInfo.value \= await invoke('get\_device\_info')  
        platform.value \= deviceInfo.value.platform.toLowerCase()  
      } catch (error) {  
        console.error('Failed to get device info:', error)  
        platform.value \= 'desktop' // fallback  
      }  
    }  
  }

  const showNotification \= async (title: string, body: string) \=\> {  
    if (\!isTauri.value) return  
     
    try {  
      const { sendNotification } \= await import('@tauri-apps/plugin-notification')  
      await sendNotification({ title, body })  
    } catch (error) {  
      console.error('Failed to send notification:', error)  
    }  
  }

  const saveFile \= async (data: string, filename: string) \=\> {  
    if (\!isTauri.value) return  
     
    try {  
      const { save } \= await import('@tauri-apps/plugin-dialog')  
      const { writeTextFile } \= await import('@tauri-apps/plugin-fs')  
       
      const path \= await save({  
        defaultPath: filename,  
        filters: \[{  
          name: 'Text files',  
          extensions: \['txt', 'md'\]  
        }\]  
      })  
       
      if (path) {  
        await writeTextFile(path, data)  
      }  
    } catch (error) {  
      console.error('Failed to save file:', error)  
    }  
  }

  onMounted(() \=\> {  
    checkPlatform()  
  })

  return {  
    isTauri,  
    platform,  
    deviceInfo,  
    showNotification,  
    saveFile  
  }  
}

**Преимущества использования только Tauri**

1. **Единая кодовая база** \- один проект для всех платформ  
2. **Единый инструментарий** \- не нужно изучать разные фреймворки  
3. **Легковесность** \- минимальный размер приложений  
4. **Безопасность** \- Rust backend обеспечивает высокую безопасность  
5. **Производительность** \- нативная производительность на всех платформах  
6. **Простота CI/CD** \- единый пайплайн сборки  
7. **Меньше зависимостей** \- не нужны Node.js и Java/Swift на продакшене
